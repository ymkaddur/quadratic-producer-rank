# Eliminating a pair of smooth gates

For the logistic function σ, σ(t)+σ(−t)=1. Therefore SiLU(t)−SiLU(−t)=t. Given a common linear input u, a common consumer weight d, opposite signs and identical routing coefficient p, two smooth branches together produce p d u t. Compiling the pair removes both exponential evaluations and leaves a quadratic action. The input t and u, the weights, the grouping and any routing overhead still count.

When route coefficients p and q differ, one residual term (p−q)d u SiLU(−t) remains. At t=1, u=d=1, p≠q this can be detected. The proof uses exact real arithmetic. Equality of the input directions alone is insufficient when the consumed coefficients differ. The identities describe a sufficient family. An exhaustive search for this syntactic pattern can miss other equivalent circuits and near cancellation requires an independent error certificate.
