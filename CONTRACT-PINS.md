# Independent statement contracts

The contract counts common squared homogeneous real linear forms with arbitrary signed output weights. Pair coordinates and paired weights give both directions of translation to the scalar specification. Changing the primitive to arbitrary bilinear products invalidates this width bound. The sigmoid identity is also stated in terms of the exponential with two distinct routing weights.

Build with the pinned Lean toolchain and run python scripts/audit_module.py ProducerPins.
